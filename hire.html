Need a hand?

The IEP Ally agent is free, and it stays free. What is not free is my time, if you want me in the room: setting the agent up for a family, training a parent group, or helping a school or clinic use AI well around neurodivergent young people.

  • Family setup session (60 minutes): install the agent, run the intake together, leave with a plan page and a meeting brief.
